# Security policy

## Supported code

Security fixes are applied to `deploy-azure-production`, the current frontend
integration branch. Historical snapshots and unmaintained feature branches are
not supported releases.

## Reporting a vulnerability

Do not place credentials, personal financial data, exploit details, or an
unpatched proof of concept in a public issue.

GitHub private vulnerability reporting is not currently enabled for this
repository, and no dedicated security email address has been published. Contact
the repository owner through their GitHub profile to establish a private
channel before sharing sensitive details. This is a known process limitation
that should be corrected before a public production launch.

Include the affected commit/version, route or component, reproduction
preconditions, impact, and a minimal safe proof. State whether credentials or
real user data may have been exposed. The maintainer will assess severity,
coordinate remediation and secret rotation, and publish an appropriate
advisory after the fix.
